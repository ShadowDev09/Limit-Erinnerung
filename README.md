# ‼️ Limit-Erinnerung GommeHD.net CB‼️
Limit-Erinnerungs-Software als Job-Limit Erinnerung für den GommeHD.net Citybuild Server

## Python installieren und prüfen
**1. Drücke "Windows + R"**

**2. Gebe "cmd" ein und drücke Enter**

**3. Gib in der CMD Folgendes ein: "winget install Python.Python.3.14"**

**4. Prüfe nun mit "python --version" ob es erfolgreich installiert wurde**

**5. Prüfe nun mit "pip --version" ob auch das richtig installiert wurde**

### Python ist nun korrekt installiert und kann verwendet werden!


## Projektordner erstellen und Dateien herunterladen
**1. Lege deinen Projektordner an (am besten ein neuer Ordner auf "C:\" Festplatte)**

**2. Lade die Datei "main.py" herunter und lege sie in deinen Ordner**

**3. Öffne deine CMD erneut und navigiere über "cd C:\" und anschließend "cd {dein Ordner Name}"**

### Dein Projektordner steht nun und du bist in ihm!


## Virtuelle Umgebung einrichten und Abhängigkeiten installieren
**1. Führe in deinem Projektordner aus "python -m venv .venv"**

**2. Warte bis alles fertig abgeschlossen ist!**

**3. Umgebung aktivieren mit: ".venv\Scripts\activate"**

**4. PySide6 darin installieren: "python -m pip install PySide6"**

### Deine virtuelle Umgebung ist nun eingerichtet und PySide6 installiert!


## Prüfen und Programm ausführen
**1. Schließe die offene CMD, öffne eine neue und navigiere zum Projektordner**

**2. Aktiviere die Umgebung wieder mit: ".venv\Scripts\activate"**

**2. Prüfe: "python -m pip --version" (sollte etwas stehen wie: "...\Dein Ordner Name\.venv\Lib\site-packages")**

**4. Um es nun auszuführen einfach eingeben: "python main.py" in der CMD**

### Das Setup ist nun vollständig fertig!


**HINWEIS - Du musst dich immer in der virtuellen Umgebung (venv) befinden, da dort die Abhängigkeiten installiert sind!**
